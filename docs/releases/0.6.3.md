Qard 0.6.3 fixes source links that could disappear, and adds renaming and batch actions for decks, topics and source updates.

- **Source links no longer disappear:** Qard could read `Qard/Source links.json` before Obsidian had finished listing the vault's files at startup, see no links, and then overwrite the file the next time you generated, linked or renamed a card. Qard now reads the file from disk in that case, and every save merges with what is already there, including a copy another device synced. A damaged file is left as it is and reported instead of being replaced. ([#11](https://github.com/kylianmarceau/qard-obsidian/issues/11))
- **Rename decks and topics:** use the pencil icon on a deck's row or beside its title, and beside a topic's Study button. Qard updates every note that holds the cards: `qard-deck` in frontmatter for decks, the heading or `qard-topic` for topics, and a location comment for cards placed some other way. Subdecks move with their parent. Card IDs, review history, deck options and exam plans are kept, and choosing an existing name merges the two. ([#9](https://github.com/kylianmarceau/qard-obsidian/issues/9))
- **Link a source note to many cards:** after **Select cards** in a deck, **Link source note** links one note or PDF to every selected card in a single save. Cards already linked to it are skipped. ([#9](https://github.com/kylianmarceau/qard-obsidian/issues/9))
- **Review source updates in batches:** when several cards are affected by note changes, **Source updates** can prepare a suggestion for each card, apply every prepared suggestion, or keep all cards as they are. Applying and keeping all ask you to confirm first, and each card goes through the same checks as a single update. ([#9](https://github.com/kylianmarceau/qard-obsidian/issues/9))
- **Current course in the tab title:** Qard's tab and window title show the course you are studying, so time trackers can record it. Turn this off under **Settings → Qard → Show current course in the tab title**.

Renaming a deck that takes its name from its note adds a `qard-deck` line to that note; the file itself is not renamed. Card IDs, review history and file formats are otherwise unchanged.

All 742 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
