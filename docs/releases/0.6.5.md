Qard 0.6.5 adds subdecks inside a deck, so a course deck can be split into sections instead of keeping every topic in one list.

- **Subdecks inside a deck:** open a deck and choose **New subdeck**. Type a name such as `ASD`, and the topics that start with it are ticked for you; tick or untick any topic by hand, then move them. Topics keep their names, cards, review history and source notes; only their deck becomes `Deck::ASD`. Choosing an existing subdeck's name adds more topics to it. Exam plans that covered the moved topics keep covering them.
- **Browsing subdecks:** a deck's subdecks appear as folders above its own topics, each with its own Study button. A deck's **Study** includes its subdecks, and a subdeck's back button returns to its parent. In the library, clicking a parent deck that has no cards of its own now opens its page; the arrow still folds it.

Card IDs, review history and file formats are unchanged. Moved cards use the existing `qard-deck` frontmatter or `qard-location` comments.

All 765 automated tests, formatting, type checking, source and stylesheet lint, build and release checks pass locally.

To install manually, download `main.js`, `manifest.json` and `styles.css` from this release and replace those three files in your vault's `.obsidian/plugins/qard/` folder. Reload Qard to apply the update. Keep `data.json`, the `study-backups` folder and your vault notes to preserve settings and study progress.
